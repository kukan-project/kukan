ベースパス: `/api/v1`

認証列の記号:

- **公開** — 認証不要
- **認証** — ログインまたは API トークンが必要
- **組織** — 組織の member / editor / admin のいずれか
- **sysadmin** — システム管理者のみ

:::note[PUT セマンティクス]
PUT エンドポイントは全フィールド置換です。リクエストに含めないフィールドは `null`（またはデフォルト値）にクリアされます。
既存値を保持するには、現在のデータを GET で取得し、変更を加えた全体を送信してください。
:::

## データセット (packages)

| Method | Path | 説明 | 認証 |
|--------|------|------|------|
| GET | `/packages` | データセット一覧（検索・絞り込み対応） | 公開 |
| POST | `/packages` | データセット作成（`resources` 配列でリソース同時作成可） | 組織 editor |
| GET | `/packages/{nameOrId}` | データセット詳細 | 公開 |
| PUT | `/packages/{nameOrId}` | データセット更新（全フィールド置換、`resources` は対象外） | 組織 editor |
| DELETE | `/packages/{nameOrId}` | データセット論理削除 | 組織 editor |
| POST | `/packages/{nameOrId}/restore` | 論理削除済みを復元 | sysadmin |
| POST | `/packages/{nameOrId}/purge` | 論理削除済みを完全削除 | 組織 admin |
| GET | `/packages/{id}/resources` | リソース一覧 | 公開 |
| POST | `/packages/{id}/resources` | リソース追加 | 組織 editor |
| PUT | `/packages/{id}/resources/reorder` | リソース順序変更 | 組織 editor |

### 主なクエリパラメータ（GET /packages）

| パラメータ | 説明 |
|----------|------|
| `q` | 検索クエリ（キーワードまたは自然文。ハイブリッド検索） |
| `semantic` | `false` でキーワード一致のみ（デフォルト: `true`） |
| `offset` / `limit` | ページネーション（最大 100） |
| `organization[]` | 組織で絞り込み |
| `groups[]` | カテゴリーで絞り込み |
| `tags[]` | タグで絞り込み |
| `res_format[]` | リソース形式で絞り込み（例: `CSV`） |
| `license_id[]` | ライセンスで絞り込み |
| `state` | `active` / `deleted` |
| `my_org` | 自分の所属組織に限定 |
| `private` | 非公開データを含む |
| `sort_by` | `updated` / `created` / `name` |
| `sort_order` | `asc` / `desc` |
| `include_facets` | ファセット情報を含める |

### 例: データセット検索

```bash
curl "https://your-kukan-site/api/v1/packages?q=人口&organization[]=stat-bureau&limit=10"
```

### スキーマとデータクエリ

CSV/TSV リソース（パイプラインでプレビュー Parquet を生成済み・≤50MB）は、**列スキーマの取得**と
**読み取り専用 SQL クエリ**ができます。AI エージェント向けには MCP の `get_resource_schema` /
`query_resource` ツールも同等の機能を提供します。

**スキーマ取得** — `GET /resources/{id}/schema`:

```json
{
  "id": "…",
  "queryable": true,
  "schema": {
    "rowCount": 1688,
    "columns": [
      { "name": "市区町村（発生地）", "type": "string", "nullable": true, "nullCount": 3 },
      {
        "name": "重量制限",
        "type": "integer",
        "nullable": false,
        "nullCount": 0,
        "stats": { "min": "600", "max": "1350" }
      }
    ]
  }
}
```

クエリ不可のリソース（非対応フォーマット・未処理）は `queryable: false`, `schema: null` を返します。
`type` は `integer` / `float` / `boolean` / `string`。`stats` は数値列のみで、整数の min/max は十進文字列です。

**データクエリ** — `POST /resources/{id}/query`:

```bash
curl -X POST https://your-kukan-site/api/v1/resources/{id}/query \
  -H 'Content-Type: application/json' \
  -d '{"sql": "SELECT \"市区町村（発生地）\" AS city, count(*) AS n FROM data GROUP BY 1 ORDER BY n DESC LIMIT 3"}'
```

```json
{
  "id": "…",
  "columns": ["city", "n"],
  "rows": [
    { "city": "足立区", "n": "117" },
    { "city": "江戸川区", "n": "110" },
    { "city": "大田区", "n": "86" }
  ],
  "rowCount": 3,
  "truncated": false,
  "elapsedMs": 31
}
```

クエリのルール:

- データは `data` という名前のテーブルとして参照します。列名に空白や非 ASCII を含む場合は二重引用符で囲みます。
- 単一の `SELECT` / `WITH` 文のみ。`INSERT` / `UPDATE` / `DELETE` / `CREATE` / `DROP` / `ATTACH` / `COPY` / `PRAGMA` 等の書き込み・DDL は拒否されます。
- 使い捨ての in-memory DuckDB 上で実行され、ファイル・URL・拡張ロード等の外部アクセスは全面的に禁止されます。

制限とエラー:

| 項目 | 値 |
|------|------|
| 最大行数 | 10,000（超過時は `truncated: true`） |
| 最大結果サイズ | 5 MB |
| 実行タイムアウト | 15 秒（`408`） |
| 同時実行 | 1（超過時 `429`） |

| エラー | 状況 |
|------|------|
| `400` | SQL 不正・非 SELECT・長さ超過・クエリ不可リソース |
| `404` | リソース不存在 / 非公開で権限なし |
| `408` | 実行タイムアウト |
| `429` | 同時クエリ上限 |
