## 必要環境

- Node.js 24+
- pnpm 9+
- Docker / Docker Compose

## セットアップ

### 1. リポジトリのクローン

```bash
git clone https://github.com/kukan-project/kukan.git
cd kukan
git checkout vX.Y.Z   # 最新リリースを指定（開発版を試す場合は省略して main のまま）
```

リリース一覧は [GitHub Releases](https://github.com/kukan-project/kukan/releases) を参照してください。

### 2. 依存関係インストール

```bash
pnpm install
```

### 3. インフラ起動

PostgreSQL、MinIO、ElasticMQ、OpenSearch を Docker Compose で起動します。

```bash
docker compose up -d
```

### 4. 環境変数

```bash
cp .env.example .env
```

### 5. データベースマイグレーション

```bash
pnpm db:migrate
```

### 6. 開発サーバー起動

```bash
pnpm dev
```

`http://localhost:3000` でアクセスできます。

### 7. 初期ユーザー登録

`http://localhost:3000/auth/sign-up` を開いて最初のユーザーを登録します。
ユーザーが1人も存在しない間は自己登録が有効で、**最初に登録したユーザーは
自動的に sysadmin（システム管理者）になります**。

CLI で作成することもできます（`--role` 省略時はデフォルトで `user`）。

```bash
pnpm db:create-user --email admin@example.com --name admin --password <password> --role sysadmin
```
