## データセットの検索

トップページの検索バーから検索できます。キーワードのほか、
「避難所の場所が知りたい」のような質問文・自然な文章でも検索できます
（キーワード一致に加えて、意味の近いデータセットも見つかります）。

### セマンティック検索

検索語と意味的に近いデータセットは、キーワードが一致しなくても結果に含まれ、
「意味的に関連」バッジが付きます。検索結果画面の「意味の近い結果を含める」
トグルでオフにすると、キーワード一致のみの結果になります。

※ セマンティック検索はサイトの構成（埋め込みモデルの設定）により
無効な場合があります。その場合はキーワード検索のみで動作します。

### どのリソースが一致したか

データセットが複数のファイルを持つとき、検索結果は**どのファイルが一致したか**まで
示します。ファイルを多く含むデータセットでは、探している内容が入っているのは
そのうちの 1 つ、ということが多いためです。
一致したリソースには、なぜ一致したかのラベルが付きます。

| ラベル              | 意味                                                                               |
| ------------------- | ---------------------------------------------------------------------------------- |
| 意味的に関連        | 検索語と意味が近いと判定されたファイル。併記される数値は近さ（0〜1、高いほど近い） |
| AI による説明に一致 | そのファイルの「[AI による説明](#ai-による説明)」に検索語が含まれていた            |
| データ内容に一致    | ファイルの中身（CSV やテキストの本文）に検索語が含まれていた                       |

一致したファイルが多いときは折りたたまれ、件数が表示されます。

### フィルタリング

- **組織** — データを公開している組織で絞り込み
- **カテゴリー** — データの分類で絞り込み
- **タグ** — キーワードタグで絞り込み
- **フォーマット** — データセットが含むリソースの形式で絞り込み
- **ライセンス** — ライセンスで絞り込み

### 並べ替え

検索結果は関連度順のほか、更新日・作成日（新しい順／古い順）や URL 識別子順で並べ替えられます。

## データセットの閲覧

データセットページでは以下の情報を確認できます。

- **メタデータ** — タイトル、説明、作成者、ライセンスなど
- **リソース一覧** — データセットに含まれるファイルや URL。セクションの見出しで
  まとめられていることがあります（見出しは検索でも一致します）
- **カテゴリー・タグ** — データの分類情報

## リソースのプレビュー

リソースページでは、ファイル形式に応じたプレビューが利用できます。

| 形式                                       | プレビュー                  |
| ------------------------------------------ | --------------------------- |
| CSV / TSV                                  | テーブル表示 + テキスト表示 |
| JSON / XML / TXT / HTML / Markdown         | テキスト表示                |
| GeoJSON                                    | 地図表示 + テキスト表示     |
| PDF                                        | PDF ビューア                |
| Excel / Word / PowerPoint                  | Office Online Viewer        |
| PNG / JPEG / GIF / WebP / SVG / BMP / TIFF | 画像ビューア                |
| ZIP                                        | ファイル一覧                |

テーブル表示になるリソースは、そのまま Excel や Tableau などの BI ツールからも開けます
（[BI ツールで開く](#bi-ツールで開く)）。

## AI による説明

:::note
**この機能は、サイトで有効にされている場合にのみ表示されます。**
無効なサイトのリソースページには、この節で説明する表示は一切現れません
（検索結果の「AI による説明に一致」ラベルも同様です）。
:::

リソースページに表示される **AI による説明**は、ファイルを開かずに中身を判断できるよう、
AI がファイルの内容を読んで書いた短い文章です。

説明の下には、**そのファイルのどこまでを読んで書いたか**が示されます。
表は列の構成と先頭の行から書かれるため「列の構成と、全 1,200 行のうち先頭 100 行を
読みました」のように、PDF は全体を読めていれば「ファイル全体を読みました」、画像は
「画像全体を読みました」と表示されます（非常に長い PDF は途中までになります）。
テキストファイルはファイルの冒頭、Office 文書などは抽出したテキストの冒頭、ZIP は
収録されているファイル名から書かれ、それぞれどこまで読んだかが示されます。**一部から書かれた場合は必ずそう明示される**
ので、要約の範囲を取り違えることはありません。

:::caution
AI による説明は、内容の正確性・最新性を保証するものではありません。
正式な内容は必ず原本のファイルを確認してください。
:::

説明には、どの版から生成したかも併記されます。ファイルが差し替えられた後、
説明がまだ更新されていない場合は「このファイルは現在 v3 です。説明は
更新されていません」と表示されます。

ファイルによっては説明が生成されず、代わりに理由が表示されます
（サイズ上限を超える、AI が読み取れない形式、など）。

## データのダウンロード

リソースページの「ダウンロード」ボタンからファイルをダウンロードできます。
外部 URL のリソースも同じボタンからダウンロードできます（元の URL にリダイレクトされます）。

## BI ツールで開く

表形式のリソースには「OData」ボタンがあります。表示される URL をコピーして、Tableau・
Power BI・Excel などの OData コネクタに貼ると、その表をそのまま開けます。ダウンロードして
読み込ませる必要はありません。

- **認証は不要**です（公開データのみ配信されます）。Tableau では認証方法に「認証なし」を選びます
- Excel では **データ → データの取得 → その他のデータ ソースから → OData フィードから**
- 貼るのは**上に表示される接続 URL**（末尾が `/Rows`）です。その下のサービス URL でも繋がりますが、
  接続後に表を選ぶ画面をもう一段挟みます — リソース 1 つにつき表は 1 つなので、選ぶものはありません
- 大きな表は自動的に分割して配信され、BI ツール側が続きを取りに行きます
- 配信されるのは**解釈後の表**です。列数の合わない行や末尾の注記など、取り込めなかった行は
  含まれません
- 行を区別するための列（`RowId`）が先頭に足されることがあります。ボタンを押すと、この表が
  どうなっているかが書かれています。不要なら BI ツール側で削除して構いません
- **主キーを後から変えると、配信される列が変わります**（`RowId` が付いたり消えたり）。すでに
  BI ツールで接続している場合、更新しても古い列のまま見えることがあります。クエリを作り直してください

見出しに括弧や記号を含む表など、この形式で配信できないものもあります。その場合ボタンは
薄く表示され、押すと理由が出ます。

## パスワードの変更

パスワードでサインインしている場合、プロフィールページから自分で変更できます。
管理者に依頼する必要はありません。

新しいパスワードは次の条件を満たす必要があります。

- **15 文字以上**
- **推測されにくいこと** — zxcvbn による強度判定（0〜4）で 3 以上

長さだけでは条件を満たしません。よく使われる単語の並びやキーボード上の並びに加え、
自分のメールアドレス・ユーザー名・表示名から作ったものも、文字数が足りていても弾かれます。
入力中に強度が表示されるので、それを見ながら調整してください。

外部の ID プロバイダ（OIDC）でサインインしている場合、パスワードはそちら側で
管理されるため、この画面には表示されません。

## API アクセス

KUKAN は REST API を提供しています。
プログラムからデータを取得する場合は、[API ドキュメント](/ja/api/)を参照してください。

表形式のリソースの中身そのものは、OData フィード（`/odata/v1/resources/{id}/Rows`）としても
読めます。BI ツールから使う場合は[BI ツールで開く](#bi-ツールで開く)を参照してください。

```bash
# データセット一覧の取得
curl https://your-kukan-site/api/v1/packages

# データセットの検索
curl https://your-kukan-site/api/v1/packages?q=人口
```
