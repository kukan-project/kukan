KUKAN は Google Analytics 4 を利用して、ページビュー・ファイルダウンロード・検索キーワードを計測できます。
この機能はインターネット公開環境向けです。閉域網（LGWAN 等）では設定を行わなければ、外部への通信は一切発生しません。

## 概要

| 計測項目 | 方式 |
|---|---|
| ページビュー | 自動（gtag.js） |
| ファイルダウンロード | ダウンロードボタンクリック時にカスタムイベント送信 |
| サイト内検索キーワード | 自動（Enhanced Measurement が URL の `?q=` パラメータを検出） |

計測データは GA4 コンソールで確認できます。GA4 Data API を設定すると、KUKAN 管理画面の統計ダッシュボードでもデータを確認できます。

## ステップ 1: GA4 プロパティの作成

1. [Google Analytics](https://analytics.google.com/) にアクセスしてログイン
2. 左下の **管理**（歯車アイコン）をクリック
3. **作成** > **プロパティ** をクリック
4. プロパティ名を入力（例: 「〇〇市オープンデータカタログ」）
5. タイムゾーンと通貨を選択
6. プラットフォームは **ウェブ** を選択
7. サイトの URL とストリーム名を入力
8. 作成後、**測定 ID**（`G-XXXXXXXXXX` 形式）をコピー

## ステップ 2: Enhanced Measurement の確認

Enhanced Measurement は通常デフォルトで有効です。以下を確認してください:

1. GA4 管理画面で **データストリーム** を開き、ウェブストリームをクリック
2. **拡張計測機能** で以下が有効になっていることを確認:
   - **ページビュー**（常に有効）
   - **サイト内検索** — `/dataset?q=...` の `q` パラメータを検出
   - **ファイルのダウンロード** — 任意（KUKAN はカスタムイベントも送信）

## ステップ 3: KUKAN の設定

ブランド設定ファイルに測定 ID を設定します:

```typescript
// apps/web/src/brand/brand-config.ts
export const brandConfig: BrandConfig = {
  // ...その他の設定
  gaMeasurementId: 'G-XXXXXXXXXX',  // 測定 ID
}
```

ファイル保存後に再デプロイしてください。`gaMeasurementId` が設定されると、すべてのページで gtag.js スクリプトが自動的にロードされます。

`gaMeasurementId` が `null`（デフォルト）の場合、外部スクリプトはロードされず、Google へのデータ送信も行われません。

## ステップ 4: カスタムディメンションの登録（任意）

KUKAN はダウンロード時に `file_download` カスタムイベントを追加パラメータ付きで送信します。GA4 レポートでこれらを利用するには:

1. GA4 管理画面で **カスタム定義** > **カスタムディメンション** に移動
2. 以下のイベントスコープのディメンションを作成:

| ディメンション名 | イベントパラメータ | スコープ |
|---|---|---|
| データセット名 | `dataset_name` | イベント |
| リソース ID | `resource_id` | イベント |
| ファイル形式 | `format` | イベント |

このステップは任意ですが、ダウンロードの詳細分析に推奨します。

## ステップ 5: 管理画面ダッシュボードの設定

KUKAN 管理画面の統計ダッシュボードでは、GA4 Data API からデータセット閲覧数・ダウンロード数・検索キーワードのランキングを確認できます。これには Google Cloud サービスアカウントが必要です:

1. GCP プロジェクト（新規または既存）に**サービスアカウント**を作成
2. GCP プロジェクトで **Google Analytics Data API** を有効化
3. GA4 管理画面 > **プロパティのアクセス管理** で、サービスアカウントのメールアドレスを **閲覧者** ロールで追加
4. デプロイ環境に以下の環境変数を設定:

| 変数 | 値 |
|---|---|
| `GA4_PROPERTY_ID` | GA4 プロパティ ID（数値、管理画面 > プロパティ設定で確認） |
| `GA4_CLIENT_EMAIL` | サービスアカウントのメールアドレス |
| `GA4_PRIVATE_KEY` | サービスアカウントの秘密鍵（PEM 形式、JSON キーの `private_key` フィールド） |

AWS 環境では、CDK コンテキストに `enableGa4DataApi=true` を追加し、値を Secrets Manager に登録します。

## 動作確認

測定 ID を設定してデプロイした後:

1. ブラウザでサイトを開く
2. GA4 の **レポート** > **リアルタイム** を開く
3. 数秒以内にアクセスが表示されることを確認
4. ダウンロードボタンをクリックし、リアルタイムに `file_download` イベントが表示されることを確認
5. 検索を実行し、`view_search_results` イベントが表示されることを確認

## よくある質問

### 閉域網（LGWAN）で使えますか？

使えません。GA4 は Google のサーバーにデータを送信するためインターネット接続が必要です。閉域網では `gaMeasurementId` を `null`（デフォルト）のままにしてください。外部スクリプトはロードされません。

### Google Tag Manager を使うべきですか？

KUKAN はシンプルさとパフォーマンスのため gtag.js を直接使用しています。GTM で管理するタグが GA4 のみのため、GTM は不要です。特別な理由で GTM が必要な場合は、コンポーネントオーバーライドで gtag.js スクリプトを置き換えることができます（[外観カスタマイズ](/ja/system-admin-guide/brand-customization/) を参照）。

### API アクセスの統計は取れますか？

GA4 はブラウザ経由のアクセスのみを計測します。`curl` やプログラムから直接 API を呼び出すアクセスは捕捉されません。サーバーサイドの API アクセス統計は別の機能として検討中です。

### データが表示されるまでどのくらいかかりますか？

リアルタイムレポートでは数秒以内にデータが表示されます。標準レポートへの反映には 24〜48 時間かかる場合があります。
