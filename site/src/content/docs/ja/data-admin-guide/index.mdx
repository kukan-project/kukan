## データセットの作成

1. ダッシュボードにログイン
2. 「データセット作成」をクリック
3. 必要な情報を入力

### 基本情報

| 項目 | 説明 | 必須 |
|------|------|:----:|
| 名前（URL スラッグ） | 英数字・ハイフン・アンダースコア・ピリオド | ○ |
| タイトル | 表示用のタイトル | - |
| 説明 | データセットの詳細な説明 | - |
| 組織 | データを所有する組織 | ○ |
| ライセンス | データのライセンス | ○ |
| 公開 / 非公開 | 非公開にすると組織メンバーのみ閲覧可 | - |

### タグ

タグを追加してデータセットを分類できます。
既存のタグから選択するか、新しいタグを作成できます。

## リソースの管理

リソースはデータセットに紐づくファイルや URL です。

### リソースの追加

- **ファイルアップロード** — ブラウザから直接アップロード（最大 100 MB）
- **外部 URL** — 外部サイトのファイル URL を指定

### 対応フォーマット

CSV、TSV、JSON、GeoJSON、XML、PDF、Excel など多数のフォーマットに対応しています。

アップロードされたファイルは自動的にパイプライン処理され、以下が実行されます。

- テキストファイルのエンコーディング検出・変換
- CSV/TSV ファイルの Parquet 変換（テーブルプレビュー用）
- ZIP ファイルのマニフェスト生成

## 組織の管理

組織はデータセットの所有単位です。

### メンバー管理

組織の管理者は、メンバーの追加・削除・役割変更ができます。

| 役割 | データセット閲覧 | データセット編集 | 削除 | 復活 / 完全削除 | メンバー管理 |
|------|:---------------:|:---------------:|:---:|:-------------:|:----------:|
| メンバー | ○ | - | - | - | - |
| 編集者 | ○ | ○ | ○ | - | - |
| 管理者 | ○ | ○ | ○ | ○ | ○ |

削除済みデータセットはダッシュボードの「削除済み」タブで組織メンバーが閲覧できます。復活・完全削除は管理者のみ実行可能です。

### 組織の削除・復元・完全削除

組織管理ページでは「公開」「削除済」のカードで表示を切り替えられます（「削除済」の閲覧はサイト管理者のみ）。

- **削除（論理削除）**: 組織をゴミ箱へ移動します。配下に**アクティブなデータセットが無いこと**が条件で、残っている場合は先に削除または別組織へ移管してください（残っている間は削除ボタンが無効になります）。
- **復元**: 「削除済」の組織を元に戻します（サイト管理者のみ）。
- **完全削除（パージ）**: 組織と、そのゴミ箱内の削除済みデータセットをファイルごと**完全に消去**します（取り消し不可。サイト管理者のみ）。処理はバックグラウンドのジョブで非同期に実行されるため、完了するまで一覧に残って見えることがあります。

## カテゴリー（グループ）

カテゴリーは組織を横断してデータセットを分類する仕組みです。
データセット作成時にカテゴリーを指定できます。

### カテゴリーのメンバー管理

カテゴリーにもメンバー管理があり、組織と同様の役割構成です。

| 役割 | カテゴリー閲覧 | データセット追加 | メンバー管理 |
|------|:------------:|:-------------:|:----------:|
| メンバー | ○ | - | - |
| 編集者 | ○ | ○ | - |
| 管理者 | ○ | ○ | ○ |
