## Searching datasets

Use the search bar on the top page to search. Besides keywords, you can also
type questions or natural sentences like "Where are the evacuation shelters?" —
semantically related datasets are found in addition to keyword matches.

### Semantic search

Datasets whose meaning is close to your query appear in the results even when
no keyword matches, marked with a "Semantic match" badge. Turning off the
"Include related results" toggle on the search results page limits results to
keyword matches only.

Note: semantic search may be disabled depending on the site's configuration
(embedding model setup). In that case search works by keyword only.

### Which resource matched

When a dataset holds several files, the results say **which file matched** —
in a dataset of many files, what you are looking for is usually in one of them.
Each matched resource carries a label saying why it matched.

| Label            | Meaning                                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| Semantic match   | The file's meaning is close to the query. The number beside it is that closeness (0–1, higher is closer) |
| AI summary match | The query appears in that file's [AI-written description](#ai-written-descriptions)                      |
| Content match    | The query appears in the file's contents (the body of a CSV or text file)                                |

When many files match, the list folds and shows the count.

### Filtering

- **Organization** — Filter by the organization that published the data
- **Category** — Filter by data classification
- **Tags** — Filter by keyword tags

### Sorting

Search results can be sorted by relevance, last updated, or name.

## Browsing datasets

The dataset page displays the following information:

- **Metadata** — Title, description, author, license, etc.
- **Resource list** — Files and URLs included in the dataset, sometimes grouped under
  section headings (a heading also matches in search)
- **Categories & tags** — Classification information

## Resource preview

The resource page provides format-specific previews:

| Format                                     | Preview                |
| ------------------------------------------ | ---------------------- |
| CSV / TSV                                  | Table view + text view |
| JSON / XML / TXT                           | Text view              |
| GeoJSON                                    | Map view + text view   |
| PDF                                        | PDF viewer             |
| Excel / Word / PowerPoint                  | Office Online Viewer   |
| PNG / JPEG / GIF / WebP / SVG / BMP / TIFF | Image viewer           |

## AI-written descriptions

:::note
**This appears only where the site has the feature enabled.** On a site without
it, nothing described in this section appears on a resource page — nor does the
"AI summary match" label in search results.
:::

An **AI-written description** on a resource page is a short piece of prose an AI
wrote from the file's contents, so you can judge what is in it without opening
it.

Below the description, a line says **how much of the file it was written from**.
A table is read as its column layout and first rows ("Read the column layout and
the first 100 of 1,200 rows"), while a PDF or an image that fit is simply "Read
the whole file" (a very long PDF stops partway). **Anything written from a part
of a file always says so**, so the extent is never left to guesswork.

:::caution
An AI-written description is not a guarantee of accuracy or currency. Always
check the original file for the authoritative content.
:::

The description also names the version it was written from. If the file has
been replaced and the description has not caught up, the page says so: "This
file is now v3. The description has not been updated."

Some files get no description and a stated reason instead (over the size limit,
a format the AI cannot read, and so on).

## Downloading data

Click the "Download" button on the resource page to download a file.
External URL resources also work through the same button (redirects to the original URL).

## Changing your password

If you sign in with a password, you can change it yourself from the profile page — no administrator involved.

A new password has to be:

- **at least 15 characters**, and
- **hard to guess** — a zxcvbn strength score of 3 out of 4.

Length alone is not enough. Common word sequences and keyboard patterns are rejected however long they are, and so is anything built out of your own email address, username, or display name. The strength meter updates as you type, so use it to gauge where you stand.

If you sign in through an external identity provider (OIDC), your password lives there and this section does not appear.

## API access

KUKAN provides a REST API for programmatic data access.

```bash
# List datasets
curl https://your-kukan-site/api/v1/packages

# Search datasets
curl https://your-kukan-site/api/v1/packages?q=population
```
